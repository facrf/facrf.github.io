Política de Privacidade

Última atualização: 2 de setembro de 2026

A sua privacidade é importante para nós. Esta Política explica como o aplicativo Fabianocesar trata as informações durante o seu uso.

1. Coleta e Uso de Informações

O aplicativo Fabianocesar é uma interface WebView para acesso ao website fabianocesar.com. Para exibir o seu conteúdo, ele utiliza a conexão com a internet.

O aplicativo, por si só, não solicita criação de conta nem coleta nome, endereço de e-mail, número de telefone, localização, contatos, fotos, arquivos, identificadores do dispositivo ou dados de uso e diagnóstico.

Eventuais informações fornecidas voluntariamente pelo usuário no website acessado pelo aplicativo serão tratadas conforme as funcionalidades e os avisos de privacidade disponibilizados no próprio website.

2. Compartilhamento de Dados e Serviços de Terceiros

O aplicativo não possui mecanismos próprios de análise, publicidade, rastreamento, autenticação ou armazenamento em nuvem. Por utilizar um WebView, o conteúdo e os recursos carregados pelo website podem seguir as práticas descritas na política de privacidade e nos avisos publicados no próprio website.

3. Segurança e Armazenamento Local

O aplicativo não mantém banco de dados próprio com informações dos usuários. Durante a navegação, o WebView pode armazenar dados técnicos locais, como cache e cookies, quando necessários para o funcionamento do website. Esses dados permanecem sujeitos às configurações do dispositivo e às práticas do website.

4. Exclusão de Dados Locais

Os dados locais do WebView, como cache e cookies, podem ser removidos ao desinstalar o aplicativo ou ao limpar os dados do aplicativo nas configurações do dispositivo. Solicitações relacionadas a dados eventualmente enviados pelo usuário no website devem ser realizadas pelos canais de contato indicados nesta Política.

5. Direitos do Titular dos Dados (LGPD)

Nos termos da Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018), os titulares possuem direitos relacionados ao tratamento de dados pessoais. O aplicativo não realiza tratamento próprio de dados além do necessário para exibir o website. Em caso de dúvida ou para exercer direitos relativos a dados fornecidos no website, entre em contato pelos canais abaixo.

6. Privacidade de Menores

O aplicativo não solicita nem coleta dados pessoais diretamente de crianças e adolescentes. O uso do website exibido no aplicativo segue as regras e avisos publicados no próprio website.

7. Alterações a Esta Política de Privacidade

Esta Política poderá ser atualizada para refletir mudanças no aplicativo ou em obrigações legais. A versão atualizada será publicada nesta página, com a respectiva data de atualização.
